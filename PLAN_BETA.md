# План беты AA Mazda Monitor (после слияния 0.8.7)

Слияние выполнено: ветка `freebuff/beta-0.8.7` → `beta` (`21f5132`).
Сборка `assembleRelease` зелёная, 25 юнит-тестов зелёные, APK
`com.aamazda.monitor.beta` 0.8.7.

Правила из `handoff_aa_mazda_monitor_BETA_nav.md` §9 действуют:
одна задача за раз по команде пользователя, версия только по команде,
`beta` не трогать без команды, `artifacts/` не коммитить, секреты не печатать,
`AppTheme`/темы не менять, README не менять без просьбы.
Приложение — для себя и энтузиастов, донаты позже.

## 0. Проверка текущего APK (на вас)
- Скачать prerelease `beta-0.8.7-<N>` из Actions, установить, открыть
  настройки: группы настроек 0.8.7 + «Дашборды AA NAV» на месте,
  редактор раскладки открывается, NAV-приложение стартует на AA.
- Проверить реген-журнал/экспорт-импорт дашбордов (новое в 0.8.7).
- Если что-то отвалилось — фикс отдельной задачей, без расширения scope.

## P2 — data-driven профили PID (универсальность под всю линейку SkyActiv-D)
Цель: Demio, CX-3, Axela, CX-30, Mazda3 и др. — без переписывания с нуля,
через профили. Стратегически: универсальность не делать «в лоб»,
переписывание отложить; реализовать через data-driven профили PID.
8. Схема профиля: набор PID + min/max/формулы/отображение, выбор по
   модели/ECU/ VIN-префиксу. Файлы: `Pids.kt`, `PidDecoding.kt`,
   `MazdaDecode`, `NavLayoutStore` (SharedPreferences `nav_layout`).
9. Источник данных: существующие датчики MazdaPids + расширение по
   моделям; пользовательский выбор профиля в настройках.
10. Тесты: unit для профиля/декодирования (расширить `MazdaDecodeTest`,
    добавить `NavLayoutStore` сериализацию).

## Что изменилось / What's changed

**Русский**

- Прожиг больше не закрывается при коротком сбросе статуса: запись завершается только после устойчивого нуля, а не при мгновенном сбросе.
- README на двух языках стал картой репозитория; добавлены раздел про свои датчики и импорт PID из Torque Pro и ограничение про формулы со ссылками на другие датчики.

**English**

- A brief status drop no longer closes a regeneration record; it ends only after a stable zero instead of a momentary drop.
- The bilingual README is now a repository map, with custom sensors, Torque Pro PID import and the limitation on formulas that reference other sensors.

## Что это

Отдельное приложение (пакет `com.aadash.nav`) для Android Auto: шаблонный
интерфейс Car App Library — приборы, графики и навигация на одном экране.
Работает параллельно с **AA Mazda Monitor**, не заменяет его; настройки и
журналы не пересекаются.

## Основные возможности

- Приборы и графики на экране автомобиля; редактор раскладки и пропорций
  (Форма, Пропорции, Вид, Элементы, Графики, Инструменты).
- Свои наборы PID и профили авто (Mazda SkyActiv-D), проверка, какие PID
  отвечают (`PidProbe`).
- Прожиг сажевого фильтра: статус в шапке, настраиваемый сдвиг и размер,
  автоскрытие после завершения, журнал прожигов с экспортом/импортом CSV.
- 24 темы приборов, светлая/тёмная/системная тема приложения, акцентный
  цвет палитрой (любой оттенок, 5 быстрых пресетов).
- Настройка размеров приборов и окошек, скрытие верхней строки, показ
  играющего трека.
- Обновление по воздуху из канала `nav` (теги `nav-…`), установка через
  AAEnabler.
- Отчёт об ошибке с журналом и файлом `.txt`, экспорт полного журнала.

## Отличия от AA Mazda Monitor (ветка `master`)

- Экран: шаблонный интерфейс Car App Library с навигацией против
  проекции приборов.
- Пакет и иконка: `com.aadash.nav`, синяя шкала против `com.aamazda.monitor`,
  тёмная шкала.
- Канал обновлений и файл APK свои: `app-nav-release.apk`, теги `nav-…`.
- Редактор раскладки и пропорций есть в nav; в master — фиксированная
  проекция.
- Master содержит больше Mazda-специфичных датчиков и проекционные
  информационные плитки; nav — гибкая раскладка и графики.
- Оба приложения можно держать на телефоне одновременно.

## Ограничения

- Визуальная проверка на реальном Android Auto-стенде не проводилась
  (нет устройства).
- Ветку `nav` в `master` не сливать; `nav.yml` на `master` не переносить.

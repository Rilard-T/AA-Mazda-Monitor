AA Mazda Monitor 0.8.4

**Русский**

- Добавлен русский и английский интерфейс (настройки, приборы, подключение к OBD, экспериментальные функции, уведомления, диалоги, датчики).
- Исправлен список PID в release-сборке (мост данных без рефлексии).
- Исправлены лишние линии в настройках в release-сборке.
- Убрано окно «Совместимость приложений Android» при установке.
- Поддержка страниц памяти 16 КБ (Android 15/16).
- Версия 0.8.4 — ставится поверх 0.8.3 без удаления.

**English**

- Added Russian and English interface (settings, gauges, OBD connection, experimental features, notifications, dialogs, sensors).
- Fixed PID list in release builds (data bridge without reflection).
- Fixed stray divider lines in settings in release builds.
- Removed "Android app compatibility" warning on install.
- 16 KB page size support (Android 15/16).
- Version 0.8.4 — installs over 0.8.3 without uninstalling.

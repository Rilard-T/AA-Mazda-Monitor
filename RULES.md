# СВОД ПРАВИЛ РАБОТЫ: AA Mazda Monitor

Документ для ассистента и для пользователя. Действует для обеих веток (`master`, `beta`); особенности беты — в разделе 6. Версия: 15.11.2026. Если правило противоречит сиюминутному удобству, действует правило.

## 1. Как отвечать

1. **Только по-русски**, коротко, без воды и без «вот мой план на 10 пунктов» там, где хватает трёх.
2. **Инструкции — «куда нажать»**: пользователь работает только с телефона (GitHub в версии для ПК в браузере + Codespaces). Никаких «запустите в IDE», «поправьте в Android Studio».
3. **YAML и подобное — одной строкой в JSON-стиле.** Многострочные блоки в мобильном редакторе ломаются на отступах.
4. **Команды для терминала** — готовые к вставке, без пояснений внутри команды.
5. В конце каждой правки: что она делает, куда нажать, что проверить.

## 2. Порядок работы над задачами

6. **Задачи — строго по одной и только по команде** («давай», «начинай», «делай»). Остальное — в очередь, а не «заодно сделаю».
7. **Перед правкой, меняющей файлы проекта, — сначала план.** Пользователь смотрит и одобряет.
8. **Сначала результат и APK — потом репозиторий.** Обновление/пуш/релиз выполняется только после явного одобрения пользователя.
9. **Версию повышать только по команде.** Не «раз изменилось — поднимем патч».
10. **Визуальные вопросы — макетом до применения.** Предлагать 2–3 варианта, ждать выбора, не выбирать за пользователя.

## 3. Сборка и релизы

11. **Подпись всегда та же**, чтобы APK ставился поверх без удаления: один keystore (CN=Echo), `versionCode` строго растёт.
12. `versionCode = major*100000 + minor*1000 + patch` (0.8.7 → 8007).
13. **Релиз на существующем теге падает** — тег под новый релиз, старые не перезаписывать.
14. Проверять после сборки: `versionCode`, `versionName`, `zipalign -P 16`, отпечаток подписи.
15. **Чейнджлоги — на русском и английском**, простым языком, только то, что важно пользователю. Текст коммита — отдельно.
16. `README.md` без прямой просьбы не менять.
17. Секреты подписи — только из переменных окружения; keystore удалять после сборки; в чат и в репозиторий не попадают.

## 4. Git

## 5. Код и проект

23. **`AppTheme` и 28 тем приборов не менять.**
24. При правке строк — обновлять `values-ru/arrays.xml` и `values/strings.xml` синхронно; захардкоженных русских строк в коде не оставлять.
25. **Не упоминать по названию стороннее приложение для дизелей Mazda** — ни в коде, ни в README, ни в UI.
26. Лицензионные пометки сохранять: GPL-3.0, авторы Kyle Agronick, Chillout, Martoreto, иконки CC BY 3.0.
27. **Всё в долях и dp**, без привязки к 1196×462: приложение должно работать на любой магнитоле и диагонали.
28. Не путать эмулятор Headunit Reloaded с реальной Mazda Connect — это разные размеры и поведение.
29. Пути файлов брать из дампа (`state.txt`), а не угадывать (`SettingsActivity.kt` — в `prefs`, `TorqueSpeedometer.kt` — в `stats`).

## 6. Метод правок в ветке `beta`

30. Правки — **идемпотентными Python-скриптами с якорями**: не совпал якорь — скрипт падает, ничего не записав.
31. Порядок: загрузить скрипт в корень → `python3 имя.py && rm имя.py` → Commit → Sync Changes → Actions.
32. Скрипты проверяются на макетах из присланных дампов; тексты в скриптах русские, лишних зависимостей нет.
33. Пользователь присылает состояние одной командой в `state.txt`, затем `rm state.txt`.

## 7. Честность

34. **Про непроверенное говорить прямо**: «код не компилировался», «в машине не проверено», «проверял только по фото».
35. Ошибки сборки разбирать по архиву логов Actions: красный запуск → ⚙ → Download log archive → искать `e:` и `What went wrong`.
36. Не выдавать «сборка зелёная» за «работает на машине» — это разные вещи, проверяет пользователь.
37. Если проверка не удалась — сказать об этом, а не объявить успехом.

## 8. Технические обходы, о которых уже договорились

38. GitHub API из воркспейса отдаёт 403 (rate limit 60/ч) — проверку обновлений и чтение релизов вести через redirect `github.com/.../releases/latest` и `expanded_assets/<tag>`, не через `api.github.com`.
39. Подмодуль `speedviewlib` в Codespaces: локально подменить адрес на HTTPS (`git config submodule.lib/speedviewlib.url https://github.com/agronick/SpeedView.git`), `git submodule sync` не запускать — вернёт SSH.
